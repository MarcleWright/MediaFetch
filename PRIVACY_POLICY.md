# Privacy Policy / 隐私政策

Last updated: 2026-05-20

## English

MediaFetch is designed to help users extract images from the current webpage, identify likely original-quality images, and download selected images.

### What the extension accesses

MediaFetch may access:

- the current webpage content needed to detect image resources
- image links and related page metadata
- URLs manually entered or pasted by the user
- local extension settings stored in the browser

### How the data is used

The accessed data is used only to:

- detect images on the current page
- identify likely original or higher-quality image versions
- support download actions requested by the user
- remember local extension preferences

### Data sharing

MediaFetch does not sell user data.

MediaFetch does not use user data for advertising.

MediaFetch does not upload webpage content, extracted image links, or user-entered links to developer-owned remote servers for analytics, profiling, or marketing.

### Local storage

MediaFetch may store limited local settings in the browser, such as download-related preferences and extension workflow settings. These settings are stored locally to support the user experience.

### Permissions

MediaFetch uses browser permissions only for extension features such as:

- accessing the active tab
- reading a pasted or copied URL when supported by the browser
- adding shortcut actions in the context menu
- extracting images from supported pages
- downloading selected files
- storing local settings

### Your control

You can stop all data access by disabling or uninstalling the extension at any time.

### Contact

If you have questions about this Privacy Policy, update this section with your public support email or contact page before publishing to the Chrome Web Store.

Suggested contact format:

- Email: `your-email@example.com`

## 中文

MediaFetch 用于帮助用户从当前网页提取图片、识别更可能为原图或高质量版本的图片，并下载用户选择的文件。

### 扩展会访问哪些内容

MediaFetch 可能会访问：

- 当前网页中用于识别图片资源的页面内容
- 图片链接及相关页面元数据
- 用户手动输入或粘贴的链接
- 保存在浏览器本地的扩展设置

### 数据用途

这些内容仅用于：

- 识别当前页面中的图片
- 判断更可能为原图或更高质量的图片版本
- 执行用户主动发起的下载操作
- 记住扩展的本地使用偏好

### 数据共享

MediaFetch 不会出售用户数据。

MediaFetch 不会将用户数据用于广告用途。

MediaFetch 不会将网页内容、提取到的图片链接或用户输入的链接上传到开发者自有远程服务器，用于分析、画像或营销。

### 本地存储

MediaFetch 可能会在浏览器本地保存少量设置，例如下载相关偏好和扩展流程设置。这些设置仅用于支持扩展功能和改善使用体验。

### 权限用途

MediaFetch 仅将浏览器权限用于扩展功能，例如：

- 访问当前活动标签页
- 在浏览器支持的情况下读取用户复制或粘贴的链接
- 在右键菜单中提供快捷操作
- 从支持的网页中提取图片
- 下载用户选择的文件
- 保存本地设置

### 用户控制

您可以随时通过禁用或卸载扩展来停止扩展对数据的访问。

### 联系方式

如果您计划将本扩展发布到 Chrome Web Store，建议在正式发布前将本节替换为您公开可用的支持邮箱或联系页面。

建议格式：

- 邮箱：`your-email@example.com`
